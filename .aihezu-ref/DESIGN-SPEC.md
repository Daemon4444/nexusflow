## 4. 核心可复用组件

### 4.1 StatCard(顶部统计卡)
```
┌────────────────────────────┐
│ ┌──┐ 标题 12 gray          │
│ │🟢│                      │
│ └──┘ 24/28 bold 大数字   │
│      副数据 12 灰字         │ ← 关键: 提供"上下文"
└────────────────────────────┘
```
- 左侧圆形 icon (背景 = 主色 12% 透明) 36×36
- 大数字下方一行小字:对比/同比/分解,**不空着**

### 4.2 GroupChip(分组标签)
```
[● max  0.3x]   浅色背景 + 圆点 + 名字 + 倍率小标
```
不同 group 不同色:max 绿、mixed 蓝、aws 橙

### 4.3 StatusChip
```
●活跃 (绿)   ●禁用 (灰)   ●过期 (红)
```
浅彩底 + 同色圆点 + 同色字

### 4.4 TokenBreakdown(明细单元格)
```
↑    114  
↓ 149.7K  99.6%  [1h]    ← 5 维分解+缓存命中率
   570
```
箭头颜色区分 input/output;百分比体现 cache hit

### 4.5 ActionIconRow(操作列)
4 个无背景图标按钮: 使用密钥 / 禁用 / 编辑 / 删除 — 灰底浅,hover 主色

### 4.6 EmptyState
```
┌─────────────────┐
│       📭        │ ← 圆角灰底图标 48
│   暂无可用渠道   │ ← 14 主文字
│   管理员尚未配置 │ ← 12 灰说明
└─────────────────┘
```

### 4.7 SectionCard
白卡 + 标题(14 bold)+ 副标题(12 gray)+ 内容,padding 20

## 5. 关键页面布局

### Dashboard
1. 4×2 = 8 个 StatCard 网格(余额/API密钥数/今日请求/今日消费 / 今日Token/累计Token/性能监控/平均响应)
2. 横向滚动「按平台拆分」(Claude/OpenAI/Gemini/Antigravity)
3. 时间范围 + 粒度切换
4. 双图: 左圆环「模型分布」+ 右折线「Token 使用趋势」(含 Cache Hit Rate 副 Y 轴)
5. **关键差异化**: 大消费数字下面始终列出 `$X.XX 实付 / $Y.YY 标准` 双价对照

### Keys 列表
- 右上角:刷新图标 + 主色 `+ 创建密钥` 按钮
- 三个筛选器横排:搜索 / 全部分组 / 全部状态
- 表格列:名称 / API密钥 / 分组(GroupChip+ 选择按钮)/ 用量(今日 + 近30天)/ 速率限制 / 过期时间 / 状态 / 操作

### Usage 明细
- 4 个 StatCard(总请求/总Token/总消费/平均耗时),每个有子数据
- 筛选:API密钥下拉 + 时间范围 + [刷新][重置][导出CSV]
- 表格列:API密钥 / 模型 / 推理强度 / 端点 / 类型(流式/按量)/ 计费模式 / TOKEN(用 TokenBreakdown)/ 费用 / 首TOKEN

### Purchase 充值/订阅
- 顶部双 tab:充值 / 订阅
- 充值流:当前余额条 → 快捷金额 500/1000/2000/5000 → 自定义 → 支付方式(Stripe/Alipay 卡)
- 订阅流:套餐卡片网格(套餐名 + 日/周/月限额 + 价格 + 购买)

### Profile
- 顶部用户卡片:绿色圆头像缩写 + 邮箱 + 三列(账户余额/并发限制/注册时间)
- SectionCard 「资料与头像」: 头像+用户名
- SectionCard 「登录方式绑定」: email/wechat/dingtalk/linuxdo/oidc 每行一个状态

### Affiliate
- 4 StatCard: 我的返利比例(5%)/ 邀请人数 / 可转换额度 / 历史返利额度
- SectionCard 「邀请返利」: 邀请码 + 邀请链接 两列(各带复制按钮)+ 使用说明 numbered list
- SectionCard 「返利额度转余额」: 当前额度 + [转入余额] 按钮

### Redeem
- 顶部大绿色渐变卡片:当前余额 + 并发数(品牌色作背景表强调)
- 中部白卡:输入框(带礼物图标占位)+ 全宽渐变绿按钮
- 底部蓝色信息卡:「关于兑换码」+ 4 条说明

### Monitor 渠道状态
- 7天/15天/30天 三 chip 切换 + Operational 状态点 + 自动刷新计时

## 6. 微文案规律
- 每页副标题用「动词 + 名词」描述本页用途:`管理您的 API 密钥和访问令牌` / `查看您的订阅计划和用量`
- 数字旁始终有上下文标签(`可用` / `今日` / `累计` / `平均`)
- group 描述写完整使用场景: `适合 Coding 场景,量大管饱` / `推荐日常使用`
- 套餐价格用 `¥478` 月费 + 三档 USD 限额组合表达
- 折扣展示双重: `享 3 折计费倍率（0.30x）`

## 7. 实现要点
- Tailwind CSS 即可还原大部分(参考用的 Tailwind)
- 字体: 系统字 sans + 数字用等宽减少抖动
- 图表: ECharts 或 Recharts
- 图标: lucide-react 或 phosphor(参考用的偏 outline + 12% 透明圆底)
- 暗色模式必备(左下角 `🌙 深色模式` 切换)
